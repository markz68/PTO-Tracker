Privacy

Records saved on this device

PTO Tracker saves time-off entries, notes, employer-reported balances, holiday templates, and preferences in browser storage. JSON backup files contain your PTO records and holiday templates. CSV files contain time-off entries.

Optional Google Drive access

When you connect Google Drive, the app uses the drive.appdata permission for PTO backup and sync. It reads and writes its PTO data in Google Drive’s application-data folder. The access token is kept in memory for the current session. Disconnecting does not delete local records or backups.

Removing your data

Local records, Google Drive app data, and exported files are stored separately. Clearing browser storage removes the local copy and can affect other apps on this same site. Export any records you want to keep first.

GitHub hosts the app. Google handles Drive and sign-in requests when you use those services.
